WEB 2 - MÉTODO CALMA AVANZADO

Abrir index.html con Google Chrome, Edge o Firefox.

ESTRUCTURA
- index.html: página principal.
- css/styles.css: diseño, medidas y animaciones.
- js/main.js: aparición de los paneles durante el desplazamiento.
- assets/images/: siete imágenes originales entregadas por el usuario.

CALIDAD
Las imágenes se muestran con un ancho máximo de 720 píxeles, que es su tamaño real.
Esto evita ampliarlas en computadoras y reduce el pixelado.

BOTONES
Los botones visibles forman parte de las imágenes. Encima de ellos se colocaron áreas
de enlace transparentes que abren Hotmart. El enlace puede cambiarse en index.html.

WEB 1
Este proyecto es independiente y no modifica la Web 1.
